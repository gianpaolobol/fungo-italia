Foto dal telefono a GitHub

Scegli le fotografie dei funghi dalla libreria iPhone, da iCloud o dai file. Nessun passaggio da Google Drive. Puoi importare fino a 20 foto per lotto e ripetere per il resto della raccolta.

Il repository Fungo Italia è pubblico: le copie inviate saranno visibili a tutti. Gli originali restano sul telefono. La conversione crea JPEG fino a 1600 pixel, rimuove GPS, EXIF e nome originale dai dati pubblicati. Non elimina informazioni eventualmente visibili nei pixel della fotografia.

Il browser vede solo le foto che selezioni. Non legge tutta Foto in background. Le identificazioni iniziali sono “non determinate”: il caricamento non riconosce automaticamente genere o specie.

1. Prepara le fotografie

Nessuna fotografia selezionata.

Anteprime e copie in attesa restano in questa pagina, senza caricamento automatico. Se chiudi o il telefono termina Safari, seleziona di nuovo le foto: quelle già registrate con lo stesso hash non vengono duplicate.

2. Collega GitHub

Il collegamento GitHub della chat non è accessibile a Safari. Per inviare direttamente dal telefono serve un’autorizzazione GitHub per questa pagina. Viene tenuta solo in memoria e inviata esclusivamente alle API di GitHub.

Collega GitHub in pochi passaggi
  1. Apri il collegamento GitHub precompilato.
  2. In Repository access scegli Only select repositories e seleziona fungo-italia. Il permesso Contents deve essere Read and write; non occorrono altri permessi.
  3. Premi Generate token. Copialo e incollalo nel campo qui sotto, poi premi Collega GitHub.

Non incollarlo nella chat. Puoi revocarlo da GitHub dopo l’importazione. La creazione precompilata è documentata da GitHub.

GitHub non collegato.

3. Pubblica le copie selezionate

Destinazione: gianpaolobol/fungo-italia, ramo photo-library, cartella photo-library/images. Il caricamento non cambia il codice su main.

Scegli le fotografie per iniziare.

Una fotografia può non bastare per determinare la specie. La successiva analisi registrerà proposte, caratteri visibili, dubbi e riferimenti; resta distinta da una revisione micologica indipendente. La libreria non autorizza il consumo.
