Assistenza Fungo Italia

Fungo Italia è un'app didattica dedicata allo studio dei funghi, al catalogo delle specie e alle esercitazioni fotografiche.

Problemi tecnici o segnalazioni

Per errori, problemi di utilizzo o suggerimenti puoi aprire una segnalazione su GitHub (richiede un account GitHub) oppure consultare le segnalazioni esistenti. Non pubblicare dati personali, foto private o coordinate precise nei ticket pubblici.

Utilizzo su iPhone

Per consultare la versione web visita Fungo Italia web. Se la versione iOS TestFlight è disponibile sul tuo account, utilizza l'app TestFlight per installare l'ultima build autorizzata.

Limiti

Le informazioni micologiche non sostituiscono la determinazione di un micologo qualificato e non autorizzano il consumo di esemplari raccolti.
