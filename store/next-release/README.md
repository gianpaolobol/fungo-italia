# Materiali del prossimo aggiornamento — bozza

`it-IT.json` contiene descrizione, novità, note per la revisione e configurazione proposta del prodotto Base. Non è caricato dai workflow della release attuale. Il file `store/it-IT.json` rimane riferito alla versione1.0.

Prima dell'uso: concludere collaudo StoreKit/UI/dispositivo; verificare copertura e dichiarazioni scientifiche; creare il prodotto Base in App Store Connect e verificarne il prezzo Italia9,99; aggiornare screenshot sul nuovo binario; risolvere lo stato operatore commerciale segnalato da Apple. La versione1.1 è la destinazione proposta, non un record già creato su Apple.

L'abbonamento annuale esistente deve essere associato correttamente alla revisione; non sostituire il binario1.0 in attesa senza gestire esplicitamente quella pratica.
